# 🎵 Spotify User Analysis 


This project analyzes **Spotify user behavior** using Python, Pandas, Matplotlib, and Seaborn. The goal is to explore user patterns, subscription types, listening behavior, and churn insights.

---

## 📂 Dataset

The dataset contains the following columns:

| Column Name             | Description                                   |
| ----------------------- | --------------------------------------------- |
| `user_id`               | Unique identifier for each user               |
| `gender`                | User’s gender (Male/Female/Other)             |
| `age`                   | User’s age                                    |
| `country`               | User’s country                                |
| `subscription_type`     | Free or Premium subscription                  |
| `listening_time`        | Total listening time (minutes)                |
| `songs_played_per_day`  | Average number of songs played per day        |
| `skip_rate`             | Percentage of songs skipped                   |
| `device_type`           | Device used (Mobile, Desktop, Tablet)         |
| `ads_listened_per_week` | Number of ads listened per week               |
| `offline_listening`     | Whether offline listening is enabled (Yes/No) |
| `is_churned`            | Whether the user has churned (Yes/No)         |

---

## 🔑 Key Insights

1. The majority of Spotify users are in the **18–35 age group**.
2. **Premium users** tend to listen more and skip fewer songs compared to Free users.
3. **Mobile devices** are the most commonly used for streaming.
4. **Offline listening** is preferred more by Premium users.
5. Free users and younger users show slightly **higher churn rates**.
6. Ads engagement is higher among Free users.
7. Gender distribution shows balanced usage but slight differences in churn and offline listening preferences.
8. Listening behavior (songs played per day, skip rate) is closely related to subscription type and affects churn.

---

## 📌 Conclusion

Analyzing Spotify user data with Python and AI tools provides **actionable insights** for improving user experience and retention. The analysis highlights patterns in user demographics, subscription behavior, device usage, and engagement metrics. These insights can guide targeted strategies for reducing churn, enhancing subscription offerings, and optimizing overall user satisfaction.
